03 / Work notes

展开看具体工作

SYSTEM / 01任务优先级与初始化

参与多任务代码梳理和模块构建，分析 NFC 巡检、USB 通信、Type-C 电源及状态检测等任务的实时性配置、线程优先级、线程栈和独立内存池，并梳理系统初始化及任务调度流程。

SYNC / 02共享 I2C 总线与模块通信

使用互斥锁、事件标志和消息队列实现任务同步与模块间通信；优化 I2C 共享总线访问策略，使核心读卡任务阻塞等待、NFC 巡检任务非阻塞访问，降低资源竞争及通信阻塞风险。

CARD / 03卡片协议与参数保存

基于 ISO7816 T=0/T=1 及 APDU 协议开发读卡相关功能，包括 PPS 参数配置和私有指令；参与 Flash 持久化重构，涉及参数校验、页擦除、QuadWord 写入、错误诊断及断电保存。

USB / 04USBX CCID 迁移与问题定位

参与 USB CDC 向 USBX-CCID 的迁移，适配 XfrBlock、Escape 回调以处理标准 APDU 与私有指令；结合 TpShell 和日志定位 64 字节 Bulk 端点接收阻塞问题，并提出优化方案。
