## 2. 信号与控制链路

```text
竞赛阶段：
赛道电磁信号 → 六路电感及模拟调理 → ADC → 滤波／归一化
 → 位置偏差 error → 转向 PD → 舵机
轮速目标与反馈 → 速度控制 → 电机驱动

拓展阶段：
编码器 → 左右轮速 ─┐
MPU9250 → 姿态／航向 ├→ 差速控制与状态估计 → 电机命令
                    └→ XY 轨迹 → UART／HC-12 → Qt 可视化
```

具体定时来源、控制周期、传感器读取方式和 ISR／主循环分工待确认。实时控制应说明“谁在何时更新数据并执行控制”，不能只列出 PID、DMP、ADC 等名词。

## 3. 六路电感、ADC 与偏差计算

每路信号从模拟调理到 ADC 数字结果，应能解释量程、偏置、饱和、噪声和通道一致性。需要确认采样是否定时触发、使用扫描／DMA 还是轮询，各通道是否足够同步。

归一化用于减少不同通道增益和安装差异，滤波用于降低噪声，但滤波会引入延迟。滤波算法、窗口和时间常数必须从代码确认，不能泛称“滤波以后更准”而不说明对控制响应的影响。

一种**仅用于解释的加权位置示例**：

```text
error = Σ(w_i × s_i) / Σ(s_i)
```

这里 `s_i` 是经过实际算法处理后的通道强度，`w_i` 代表位置权重。它不是本项目已核实的公式；实际可能是差比和、左右通道组合或分段规则。分母接近零时必须有处理，还要定义丢线、交叉区域、尖弯及信号饱和等状态。

要补一组“六路原始值 → 处理后数值 → error → 控制输出”的真实样本，才能把算法讲具体。

## 4. 速度环、转向 PD 与调参

### 4.1 控制结构

若速度环确实有编码器反馈，按“目标轮速 → 误差 → 控制器 → 电机 → 编码器反馈”说明。若某阶段没有轮速反馈，就不能把按固定占空比驱动说成速度闭环。

转向 PD 典型作用为比例响应偏差、微分抑制快速变化，但实际符号、离散实现和输出限幅要与车体方向一致。微分对噪声敏感，采样周期、滤波和执行器饱和都影响效果。

### 4.2 “分段／模糊 PID”到底指什么？

- 按偏差或弯道状态切换几组参数，可能更准确地叫分段控制或增益调度。
- 如果确实采用模糊控制，应说明输入、隶属函数、规则、输出参数以及如何映射到离散控制器。
- 不要只因为参数会改变，就宣称实现了完整模糊推理或自适应控制。

调参应准备真实过程：先确定方向和限幅，再逐步调整响应，观察直道、入弯、出弯及不同速度；用实际误差／轮速／输出曲线说明振荡和超调。没有对照记录，不补造“误差下降多少”或竞赛成绩。

## 5. MPU9250、DMP 与姿态

简历写通过 I2C 读取 MPU9250，并调用 DMP 输出四元数后转换为 roll／pitch／yaw。应区分器件／第三方库完成的处理与自己完成的读取、坐标变换、校准和应用集成，不能直接说姿态融合算法完全自研。

需要核对：实际 DMP 固件／库、输出率、是否使用磁力计，以及四元数代表的坐标系。MPU9250 有九轴传感器，不等于当前 DMP 输出必然采用全部九轴，也不等于 yaw 已经获得稳定的绝对航向。

陀螺仪零偏会导致角度随时间漂移；加速度计受重力和运动加速度共同影响；磁力计需要考虑校准和电机／环境磁场干扰。实际采用哪些补偿和融合步骤，以代码为准，不能凭传感器型号补出 EKF 等算法。

Euler 角便于理解，但要注意单位、范围、轴顺序和奇异姿态；四元数转换后得到数值，并不自动保证坐标系与车体控制方向一致。

## 6. 差速转向与角速度补偿

用理想平面差速模型解释时，可写：

```text
车体线速度 v = (v_right + v_left) / 2
车体角速度 ω = (v_right - v_left) / b
```

`b` 为左右轮有效间距，轮速单位应一致；实际四轮结构、轮胎打滑、传动和有效轮径会影响模型。上式是背景模型，不代表项目代码完全照此实现。

“角速度前馈”需结合控制框图核对：若输入来自目标转弯运动，可讨论前馈；若用实时测得的陀螺仪角速度抑制摆动，也可能实质上属于角速度反馈／阻尼。不能只沿用一个名称而说不清信号从哪里来、加在哪个环节、符号如何确定。

要补控制目标、编码器／gyro 输入、左右输出及限幅，说明拓展阶段为何优于原方案，效果以实际记录为准。

## 7. 轨迹推算与上位机

若用编码器估计前进速度、用融合航向 `ψ` 更新位置，一个**解释性离散模型**是：

```text
x_next = x + v × cos(ψ) × Δt
y_next = y + v × sin(ψ) × Δt
```

需要说明速度来源、时间戳、航向来源、起始坐标及同步方式。不能把“读取 IMU”直接等同于“靠加速度积分得到准确 XY”。编码器里程计也受轮径误差、滑移和航向误差影响，积分时间越长误差可能积累。

HC-12 在简历中承担无线串口链路，需补实际串口帧、发送频率、模块配置和丢帧处理；Qt 需要正确解析数据、处理坐标与单位并更新显示。能画出一条轨迹不等于定位精度已验证，应与已知距离／形状或外部参考作对照。

## 8. 软硬件联合排障与验证

可以准备但不能当作已发生的故障：ADC 通道饱和、舵机抖动、电机干扰 IMU、电源压降导致复位、UART 丢帧、坐标轴符号错误、积分漂移。

排查按证据分层：电源／接线 → 原始采样 → 数值转换 → 控制量 → 执行器 → 运动结果。优先记录同一时间轴上的传感器、error、目标／实际轮速、控制输出、姿态和任务／中断耗时，再决定是硬件噪声、控制参数还是调度问题。

若负压系统使用风机，应按实际电路说明负载、电源预算与噪声影响；没有测量不能直接认定它是某次故障根因。
